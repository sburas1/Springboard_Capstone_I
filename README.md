# Springboard_Capstone_I

This project uses Tableau to explore and analyze patterns in hotel booking cancellations. The dataset includes booking information for two types of hotels — City Hotel and Resort Hotel — and provides insights into customer behavior, seasonal trends, and cancellation rates.

## 📊 Project Objectives

- Identify trends in hotel booking cancellations.
- Analyze how factors like hotel type, customer type, booking time, and family status affect cancellation behavior.
- Create interactive visual dashboards to communicate key findings.

## 🧰 Tools & Technologies

- **Tableau**: For data visualization and dashboard creation
- **Excel**: For initial data cleaning and filtering
- **GitHub**: For version control and sharing the project

## 📁 Files in This Repository

| File | Description |
|------|-------------|
| `Hotel_Booking_Cancellation_Analysis.twbx` | Tableau packaged workbook containing all dashboards |
| `hotel_bookings.csv` | Original dataset used for analysis (from [Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)) |

| `dashboard_screenshots/` | Folder with images of dashboards for quick preview (optional) |

## 📈 Key Insights

- City Hotels had a higher cancellation rate compared to Resort Hotels.
- Cancellations were more likely when bookings were made far in advance.
- Customers without children or babies were more likely to cancel.
- Cancellation trends showed seasonal peaks, particularly around holidays.

## 🔍 Dashboard Features

- **Cancellation Overview**: High-level stats and trends by hotel type.
- **Booking Behavior**: Analysis by lead time, deposit type, and customer type.
- **Family Status & Wait Time**: Deep dive into non-family bookings and short wait periods.
- **Time Series**: Monthly and yearly trends in cancellation behavior.

## 🚀 How to Use

1. Download the `.twbx` file and open it in Tableau Desktop.
2. Use the filter controls to explore data segments.
3. Optionally, open the raw dataset in Excel or your preferred tool for additional exploration.
